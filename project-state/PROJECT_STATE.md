## 0. Đọc nhanh (dành cho người hoặc AI mới vào dự án)

**STAVE** là web app áp dụng version control kiểu Git (commit, nhánh, hợp nhất, so sánh, khôi phục) cho dự án nhạc MIDI. Nguyên tắc sản phẩm: "Google Docs, không phải MS Word" (không làm DAW). Quy ước ổn định nằm ở `CLAUDE.md` (đọc trước); file này chỉ ghi hiện trạng.

**Cấu trúc:** monorepo npm workspaces. `frontend/` (Next.js 16, Tailwind 4, Tone.js), `backend/` (NestJS, Socket.IO), `shared-types/` (kiểu dùng chung, không có test runner riêng). Dữ liệu ở Supabase (Postgres, Auth, Storage). Backend mỗi module một thư mục dưới `backend/src/` (`projects`, `drafts`, `commits`, `branches`, `merge`, `pull-requests`, `forks`, `collaboration`, `jam`, `explore`, `ai`, `project-access`…).

**Lệnh:** `npm install` ở gốc. Chạy: `cd frontend && npm run dev` (3000), `cd backend && npm run start:dev` (3001). Kiểm tra: `cd backend && npm test` (Jest, **1542** ca ở 73 file), `cd frontend && npm test` (Vitest, **608** ca ở 28 file), `cd frontend && npx playwright test` (E2E, cần DB test, xem mục 3). CI (`.github/workflows/ci.yml`, chạy ở PR vào `main`): frontend build + lint + vitest, backend build + lint + jest, backend-integration (bỏ qua nếu thiếu secret). CI **không chạy E2E**. `npm run lint` của backend có `--fix` nên tự sửa định dạng.

**Bất biến cần nhớ** (chi tiết ở CLAUDE.md mục 4): một commit là một snapshot JSON đầy đủ (`notes[]` phẳng, tick nguyên, `schemaVersion` 3); nháp theo nhánh đang mở, ghi bằng khoá lạc quan (`DRAFT_STALE` 409); mọi endpoint cần đăng nhập đi qua `JwtAuthGuard` rồi `SessionAuthGuard`; quyền ghi dùng `assertCanEdit`/`assertOwner`, quyền đọc lịch sử dùng `assertCanRead` (người đã đăng nhập đọc được project công khai); `commits` và `admin_audit_log` chỉ thêm, không sửa/xoá; AI chỉ viết câu diễn giải, không bao giờ chặn commit/merge; màu diff đi qua token `--diff-*`.

**Kiểm tra đầu vào nháp/commit (backend, từ 06/11/2026):** note `velocity` 1–127, `start` ≥ 0, `duration` ≥ 1; track `volume` 0–1, `pan` −1…1; tối đa 32 track; lời nhắn khôi phục ≥ 1 ký tự. **Số track tối thiểu là 0** (project mới bắt đầu không có track; ràng buộc "tối thiểu 1 track" đã bị loại vì làm hỏng tự động lưu).

**Quy ước test:** tên ca mang mã trùng sheet Report 5 (`BE-CMT-01 UTCID03`, `FE-LIB-12`…) để đếm tự động; `it.failing` đánh dấu lỗi đã biết kèm mã DFID và phải gỡ khi lỗi được sửa; spec backend dựng service bằng `ProjectAccessService` thật trên mock Supabase (`backend/src/test-utils/supabase-mock.ts`, hàng đợi theo bảng, lọc theo `.eq`); test frontend phải ghim ngôn ngữ (`setLang('vi')`) vì app mặc định tiếng Anh; test tự động **không bao giờ** ghi vào DB production (dùng DB test); `docs/Report5_Unit Test.xlsx` do nhóm tự điền.
