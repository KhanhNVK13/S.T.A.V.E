PHẦN F. Kiểm tra cuối trước khi nộp

  7. Báo lại: sheet nào đã xong, ca nào còn fail và lý do, để ghi vào PROJECT_STATE.md.


CHỈ DẪN CHUNG
-------------
A. Đặt tên test (bắt buộc, để đếm kết quả tự động)
   - describe có mã sheet:  describe('BE-JAM-11 JamService.createEvent', () => { ... })
   - mỗi it bắt đầu bằng UTCIDnn, đúng thứ tự cột của sheet:  it('UTCID01 creates a scheduled event ...', ...)
   - Mẫu có sẵn: backend/src/projects/projects.service.spec.ts và các spec đã gắn mã (forks, jam, collaboration...).
     Frontend: frontend/lib/*.test.ts (các file music-theory, paste-pattern, zip-store đã gắn mã).
   - Số test phải bằng số cột UTCID của sheet. Cần thêm ca thì thêm cột vào sheet (copy cột liền kề).

B. Chạy test
   - Backend (Jest): cd backend ; npx jest src/jam/jam.service.spec.ts ; npx jest (toàn bộ)
   - Frontend (Vitest): cd frontend ; npx vitest run lib/validation.test.ts ; npx vitest run (toàn bộ)
   - Lint: npx eslint <file> (cả frontend và backend). Không dùng "npm run lint" ở backend (tự sửa file).
     Backend dùng Prettier: npx prettier --check <file>.
   - KHÔNG chạy test ghi vào DB production. Test ở đây đều mock, không cần kết nối DB.

C. Điền kết quả vào workbook
   - Ô Passed/Failed từng cột: P hoặc F. Ô Executed Date: chữ dd/mm/yyyy (ví dụ 04/11/2026).
   - Có ca fail: ghi mã lỗi ở dòng Defect ID và thêm vào docs/testing/defects-list.md.
   - Theo docs/testing/unit-test-guide.md: test fail do CODE sai thì sửa code (nhánh bugfix/), không sửa test
     cho khớp lỗi. Test fail do SHEET sai thì sửa sheet và ghi lại.
   - Workbook có công thức tự tính Passed/Failed/Untested; không gõ tay các ô đó.
   - Đóng Excel trước khi thay file bằng công cụ khác (file đang mở bị khoá).

D. Git (theo CLAUDE.md mục 8)
   - Nhánh: test/<mô-tả-ngắn>, ví dụ test/commits-service-unit-tests (chỉ thêm test, không đổi logic).
   - Tạo nhánh từ main mới nhất, mở PR, người khác review. Không push thẳng main. Chia PR nhỏ theo nhóm
     (ví dụ một PR cho commits, một cho drafts + shared-types, một cho frontend).
   - Commit message tiếng Anh, thì hiện tại: "Add unit tests for CommitsService".
   - Gặp lỗi code thật: nhánh bugfix/ riêng, không sửa lẫn trong nhánh test.
