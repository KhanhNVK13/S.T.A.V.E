    04 · The idea · WhySTAVE

    Three reasons to save every version

    Experiment without fear

    Branch to try a different arrangement. The original stays untouched on the main branch.

    Know exactly what changed

    Compare two versions note by note, grouped by bar, with color for added, removed and changed notes.

    Go back at any time

    Restoring creates a new commit, so old history is never lost.

    05 · The guide · How it worksSTAVE

    From draft to final

    01

    At the start, you just write. Your draft autosaves on every change, so closing a tab by mistake or losing connection never costs you a note.

    Draft saved at 14:0238 uncommitted notes
    02

    When a section feels right, you commit and name that moment. Only commits enter the history, so it stays tidy instead of a pile of autosaves.

    Commit
    03

    To try another direction, you branch. The original stays untouched on the main branch; scrap it if it fails, keep it if it works.

    main6 commit
    bridge-alt2 commits · 2 ahead, 1 behind
    04

    When you’ve chosen, you merge. If both branches edited the same note, STAVE groups the conflicts by bar so you can choose each one.

    2 conflicts in bars 5 and 6Open the resolver
